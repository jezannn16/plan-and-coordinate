# Plan and Coordinate

[English](README.md) · [Русский](README.ru.md) · [Español](README.es.md)

**Дорожная карта превращается в план, по которому можно работать.**

Навык для ИИ-агента, который разбивает релизы на задачи и помогает координировать людей или агентов через общую доску.

## Что делает

Разворачивает планы релизов, создаёт отдельный план для каждой фазы и распределяет задачи с учётом зависимостей и блокировок.

## Как работает

Сначала уточняет границы релизов и задачи, затем при необходимости создаёт доску AGENTS-STATUS.md.

## Требования

Некоторые режимы ссылаются на навыки Superpowers. Протокол координации использует Git-коммиты, push и цикл ожидания; изучите его перед запуском.

## Установка

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/jezannn16/plan-and-coordinate.git ~/.agents/skills/plan-and-coordinate
```

## Пример запроса

> Разбей эту дорожную карту на планы по релизам, затем предложи доску координации.
